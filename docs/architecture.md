# 架构与维护约定

[文档导航](guide/README.md) · [开发与部署](guide/development.md) · [当前状态](STATUS.md)

本页保留继续维护需要的核心约定。历史规划、逐阶段审计和原始验收报告只留在开发机，不再作为公共仓库内容。

## 数据与事务

作品模型定义于 [src/domain/types.ts](../src/domain/types.ts)。页面、图层、原图资源、素材文件夹和组件预设属于作品数据；选择、视口、活动草稿、全局首选项和面板布局分别维护，不混入正式内容。

所有内容修改经过 [commandBus](../src/history/commandBus.ts)。交互先建立草稿，确认时一次提交；取消恢复原状态。预览不能逐帧进入撤销历史。复制、预设、保存和迁移必须保持对象引用、资源归属与编号一致。

当前内部schema为12。增加字段或类型时同步修改工厂、校验、迁移、复制、预设、渲染和文件编码，不通过改版本号掩盖不兼容数据。

绘画源由`src/freehand/`与`src/bubbles/`实现。主画布B工具保留原始轮廓，松手直线补口并校验完整闭合边。气泡源V2保存基础轮廓、修形及独立有序细节笔迹；源V1迁移时补空细节，不丢旧数据。细节擦除只作用于独立笔迹缓冲，按实际输出坐标256px分块重放，LRU上限16MiB。最终区域进入同一个描边、文字、尾巴和融合渲染链。素材同时保存笔迹与透明PNG；作者源SHA-256参与去重，文件打开、目录读取和恢复校验源摘要。重画素材实例使用新资源ID，不能覆盖共享原件。

自由绘画窗口仅创建／重画素材，拥有独立草稿、局部历史及Canvas，笔迹不逐帧写主文档。预览按当前对象之前、活动绘画、当前对象之后和控制框分层，保持画序；所有资源先准备、完整候选先验证，确认基准仍有效后才以单一事务应用。取消释放私有缓冲，不留下半批对象。

## 坐标和几何

二维矩阵存为 `[a,b,c,d,e,f]`，局部点转换到父坐标：

```text
x' = a*x + c*y + e
y' = b*x + d*y + f
world(layer) = world(parent) * local(layer)
localPoint = inverse(world(layer)) * pagePoint
// 多选：T是共同页面空间仿射，选中祖先时移除其选中后代
localNew = inverse(world(parent)) * T * world(original)
```

实现以 [geometry/matrix.ts](../src/geometry/matrix.ts)为准。几何命中、节点编辑、素材裁剪及导出必须使用相同的坐标约定；不能把嵌套容器的属性坐标当作页面绝对坐标。退化、自交和非有限值由对应校验拒绝。

## 渲染和交互

[compileScene](../src/render/compileScene.ts)与[drawScene](../src/render/drawScene.ts)维护实际画序和裁剪关系，供编辑画面、缩略图与成品使用。拖动、节点、文字框、遮罩和手绘预览使用独立交互层，保留祖先裁剪与原画序，不能临时把对象置顶来代替正确重放。

分镜序号、选择框、节点和辅助线只出现在编辑层。输出预算见 [domain/limits.ts](../src/domain/limits.ts)；超限必须提示，不能静默降低倍率或丢弃内容。

## 分镜、素材和文字

- 分格产生同级独立分镜；分镜可关联图片，普通组件归属普通组或页面。
- 普通分镜编号为全项目当前最大号加一。切割目标 k 为 N 块时，新号为 k～k+N−1，后续现存号加 N−1，自动名称同步，自定义名称保留。
- 素材实例与库原图区分。实例裁剪改变源窗及选择范围，遮罩控制可见部分；两者都保留库原图。破格只解除对应所属分镜的裁剪。
- 主对白区分自动框、手动换行框和旧手调位置。按实际字体测量墨迹，文本内容保留；不能用估算字符宽或缩字来伪造居中和无溢出。
- 组件预设生成独立副本；笔刷预设保存参数。它们随当前作品保存，全局快捷键和面板布局则留在浏览器站点。

## 可编辑外观

`LayerBase.presentation`保存整体opacity、混合、描边与有序效果；无该字段的旧对象沿用旧绘制。`decoration.shape`是真正的普通矢量轮廓，不使用隐藏分镜编号模拟。外观预设保存在作品的stylePresets，独立于保存整个组件的templates。

`src/appearance/commands.ts`负责私有预览、文本编辑收尾、锁定／选区／epoch守卫和一次提交。九点基准与比例链为会话状态；矩阵是真值，倾斜分解提示只有在重建矩阵吻合时使用。转换分镜前必须克隆迁移返回的候选，不能修改共享roots数组。

外观预览复用独立Konva Layer和静态／动态paint runs。连续贡献分段隔离保持画序；图层内容先合成后应用整体opacity。逐填充／描边混合使用实际backdrop和premultiplied alpha恢复有效源。共同祖先裁剪只在合成处应用，素材自己的普通／局部破格剪裁仍约束效果。连续对白使用共享Surface与组外观，成员原独立外观保留供解散后恢复。

效果的扩张使用二遍精确欧氏距离变换；模糊、大小和偏移按绘制矩阵转换。临时外观缓冲限256MiB，变宽描边缓冲限64MiB；屏幕、取色、缩略图和PNG/PDF共用绘制路径。额外效果内存进入导出预检，不能暗降倍率。真实预览／导出像素及DPR测试见tests/e2e/referenceProperties.spec.ts。
