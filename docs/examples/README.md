## city.svg

[city.svg](city.svg)是文档专用的城市背景，尺寸 **1200 × 700 px**。由矩形、圆形和路径组成，没有脚本、外部引用、字体或嵌入图片。

它已通过当前 Comia 素材库的实际导入流程，用于首页和素材库截图。下载／取得仓库内的原文件后，用 **素材库 → ＋ 导入图片**选择它。不要把页面截图作为素材来代替原图。

要复现示例，创建 1200 × 900 px 页面，添加“上大下二”版式，将该素材分别放入三个分镜，再添加中英文对白。详见[快速上手](../guide/getting-started.md#first-comic)。

城市素材由本项目文档制作，未使用外部图库。目录未包含用户作品、外部商业素材或字体。示例说明不为项目源码额外授予开源许可；项目和字体许可分别见[首页许可说明](../../README.md)。
