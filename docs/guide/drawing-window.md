# 自由绘画窗口：创作手绘素材

[文档导航](README.md) · [独立手绘气泡](hand-bubbles.md) · [快捷键](shortcuts.md)

自由绘画窗口用于多色绘画和新素材创作。气泡使用主画布的独立 **手绘气泡** 工具；在本窗口画圆或闭合线条仍是普通素材。

![实际素材绘画窗口：透明画板、对象列表、画笔与橡皮](../assets/drawing-window.png)

## 创建与应用

1. 点击工具栏的 **自由绘画窗口**，或选择 **编辑 → 自由绘画窗口…**。
2. 点击 **＋ 新素材**，用画笔绘制。可调整笔宽、颜色、透明度和平滑程度；橡皮只擦当前对象。
3. 再次点击 **＋ 新素材** 创建独立对象，从左侧列表切换。可改名、隐藏或删除新对象。
4. 点击 **应用到画布**。有效对象成为独立素材图层，保留相对布局，整体放在页面中央，并加入素材库。

棋盘格表示透明区域，不参与导出。空对象不产生占位图层；全部为空时会提示先绘制。取消有内容的窗口时，可继续绘画或放弃草稿，放弃不会改变漫画。

入口默认无快捷键，可在 **文件 → 首选项 → 快捷键** 中设置。`B`进入主画布手绘气泡工具。

## 修改手绘素材

选中本窗口创建的素材实例，在属性或右键菜单选择 **在绘画窗口编辑**。保留原笔迹，可以继续画、擦除和调整。重新应用只替换该实例的资源，其他实例和库中原件不被覆盖；已有裁剪、遮罩和分镜关系保留。

导入照片和背景图片继续使用裁剪、遮罩及破格工具，本窗口首版用于创建新素材。旧手绘气泡仍可打开作品并编辑，但其笔刷编辑入口已移到主画布，见[气泡说明](hand-bubbles.md)。

## 移动、缩放与撤销

选择 **移动／缩放**，在操作框内拖动当前对象，拖右下角调整大小；也可输入位置和横纵倍率。重开窗口只编辑该目标，不能在同一次重开中插入其他对象。

窗口内 `Ctrl+Z`／`Ctrl+Shift+Z` 处理局部历史，输入框保留自己的文字编辑。一笔绘画或一次属性确认产生一个局部历史；**应用到画布** 才产生一次漫画事务，可整批撤销。重开后无改动直接应用不会增加历史。

失焦、指针中断或切换活动对象会取消未完成的一笔；已完成笔迹保留。作品或目标在准备应用时发生变化，旧草稿不能写入新状态。

## 当前边界

- 默认画板1024×768，创建对象前可修改，每边16～4096像素。
- 每窗口最多16个对象；单笔8192点，每对象65536点、256次绘画操作。
- 缓冲估算上限256MiB，超过时提示减少对象或尺寸，不静默缩图；估算不等于进程总内存。
- 保留Comia项目才能继续修改原笔迹，PNG／PDF是成品。

这些容量限制是暂定产品策略，实际核验范围见[项目状态](../STATUS.md)。
