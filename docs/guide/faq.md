## 启动与浏览器

### 安装或启动提示 Node 版本不满足？

先运行 `node --version` 和 `npm --version`。当前要求 Node **22.12.0+**、npm **10+**。不要假定 Node 18 能运行此项目，也不要用全局最新版 Vite 替代锁文件里的版本。

安装符合要求的环境后，在项目目录执行 `npm ci`。如果锁文件与依赖声明不一致，保留报错并排查仓库修改，不要为了消除错误直接删除锁文件。

### 5173 端口被占用，或打开了其他应用？

严格端口启动会直接提示占用。先确认现有进程是否就是 Comia：若是，直接使用现有地址；否则换一个端口：

```powershell
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

然后打开 5174。不同端口是不同浏览器站点，本地恢复与首选项不会跟着迁移。不要结束不明进程；正在编辑的作品先保存。

### 为什么不能双击 dist/index.html？

应用依赖 HTTP 提供模块、字体与资源；`file://` 方式不受支持。用开发服务，或执行 `npm run build` 后使用 `npm run preview`。正式部署见[静态部署说明](development.md#deployment)。

### 是否有账户、云同步、手机应用或 AI 生成功能？

当前没有 Comia 账户、云同步或原生手机应用。界面对窄屏有面板收纳，但主要按桌面编辑场景使用。AI 生成分镜仍是待定候选，**随机分格是几何生成，不是 AI**。也不支持 PSD 导入导出。

## 工具、选择与面板

### 为什么点击总选中分镜，选不到里面的图片？

在 `V` 移动工具中按住 **Alt 单击图片**；需要多张时用 **Alt+Shift+单击**。也可以展开分镜图层，选图片子层。图片被隐藏或锁定时先检查图层状态。

### 怎么选择多个对象，画布上是否会反馈？

`Shift+单击`逐个追加；`M`矩形框选或`L`套索圈选。画布会显示所有已选对象的框，图层列表也会高亮。按 `V` 后拖动可以整体移动。

如果只选到一个组，说明当前范围按组整体选择；进入组内层级再操作。跨层级、隐藏、锁定、页面背景与选择范围都会影响结果。

### 套索为什么不能复制图片中的人物像素？

目前矩形和套索选中完整组件或素材实例，不是像素区域。可使用图片遮罩隐藏周边，再配合破格；需要精细抠图时先在图像处理工具生成带透明度的素材。

### 节点拖动像“卡住”，怎么自由拖？

这是横纵与相邻节点的磁性辅助，不是掉帧。明显偏离后会脱离；按住 **Alt**临时自由拖动。精确调整可用 `Ctrl+方向键`，加 Shift 每次移动 10 页面像素。

### 面板不见了、挤到屏幕外或没有滚动条？

在 **窗口**菜单重新显示对应面板；用 **恢复默认工作区**恢复布局。内部滚动条被隐藏，仍可滚轮滚动，也可点击标题展开按钮，在大窗里查看内容。

拖动标题移动整组，拖标签分离单个面板。关闭面板不删除作品；它与删除图层不同。

### 点击组件为什么直接放进画布？

这是当前创建方式：普通组件点击即在页面中心放置并选中，不需二次点击画布。拖放可以指定位置。速度线等笔刷参数预设则会启用笔刷，等待你绘制新的一笔。

## 分镜与编号

### 新分镜为什么不是填最小的中间空号？

普通创建使用**当前实际最大号 + 1**。现存 1、3、4 时创建 5；删除末尾到只剩 1 时创建 2。这样保留中间删除痕迹，又复用已下降的尾号。

编号在整个漫画内唯一，其他页面的分镜也参与最大值计算。看似空页从较大编号开始时，先检查其他页面。

### 切割为什么让其他分镜编号也变了？

切割在目标号处连续插号。例如切 1 为三块，新块为 1、2、3，原 2、3 顺延为 4、5。此规则与普通新建不同，撤销一次可恢复该次切割与相关编号。

### 为什么带破格图片的分镜无法继续切割？

当前切割会复制框内图片并保持各块映射；破格区域的跨框归属不能直接套用该规则。先将图片改为普通模式或解除分镜关联，再切割；之后对需要的实例重新配置破格。

### 为什么生成后下排右边是 2、左边是 3？

默认按日式漫画右到左、上到下阅读。可在页面面板设置漫画阅读方向，用于之后的批量生成；不会因移动对象而重新排序旧编号。

### 分镜序号如何隐藏？为什么成品没有数字？

用 **视图 → 显示分镜序号**切换。序号是编辑标识，本来就不输出到 PNG/PDF；需要成品编号时自己添加文字组件。

### 随机分格或版式为什么不能一次改所有框？

生成的是独立同级分镜，方便逐框编辑。想整体调整，先多选，再移动或编组；需要某一框内容，展开对应分镜的图片子层。

## 素材、裁剪与遮罩

### 图片被白色区域挡住了？

检查挡住它的是哪个图层：新分镜默认透明，但旧分镜或手动设色的分镜可能填充不透明白色。调整该分镜填充 Alpha／透明度，或改变图层顺序。

最底层“页面背景”的白色不会遮住上层图片；关闭整页背景也不能解决上方分镜的不透明填充。

### 绑定分镜后图片还能编辑吗？

可以。`Alt+单击`图片后移动、变换、裁剪或改遮罩。旧适配图片先用 **自由编辑素材**转为自由编辑；要解除分镜裁剪，用解除关联或破格属性。

### C 与 Shift+C 到底有什么区别？

- **C 裁剪**改变当前素材实例的源范围和选择框。
- **Shift+C 遮罩**只隐藏部分区域，保留当前实例选择框。

两者都不删素材库原图。删除遮罩后仍裁着，是因为实例裁剪仍有效；使用 **恢复裁剪**才恢复全范围。

### 破格打开了，为什么还是有部分看不到？

破格只解除所属分镜边界的裁剪。图片自身遮罩、实例裁剪、页面范围及其他祖先约束仍然生效；上方图层也仍会遮挡它。检查这些约束，并按需要调整层级。

### 删除素材文件夹或“移出素材库”会删除画布图片吗？

不会。删除文件夹把内容移到上级；移出素材库只移除库条目，已经放置的实例保留。删除实例也不会反向删除库原图。

### 导入失败、重复素材没有移到新文件夹？

先检查支持格式、大小与像素数。当前单原图上限 **50 MiB**、**4000 万像素**，累计原图上限 **512 MiB**；解码失败会显示具体原因。

同内容去重后保留原条目和原分类，选择新的文件夹导入同一图不会自动搬动它。请手动调整分类。

### SVG、GIF 或 AVIF 为什么不是原软件里的效果？

SVG 只接受安全支持的几何、局部渐变和裁剪等子集，脚本、外部引用、嵌入图片、文本、滤镜等复杂内容可能拒绝。请先转换为 PNG。

动画素材作为静态首帧使用，不播放动画。AVIF 等解码能力取决于浏览器；不能可靠识别或解码的文件会拒绝，而不是保证支持所有编码变体。

## 气泡、文字与字体

### 手绘气泡为什么没有生成？

`B`在松手时自动连接首尾，不需要手动闭合。自动连接段若与轮廓交叉，或线条退化、超出点数预算，会拒绝整笔；重新画出简单轮廓即可，不用再次点击完成。需要多色涂鸦时用自由绘画窗口创建素材。详见[手绘气泡](hand-bubbles.md)。

错误时先修正，不要为了通过而静默降低导出倍率。取消不会生成空气泡层。

### 气泡文字怎么居中？英文和中文一样吗？

新主对白默认在主体安全区横纵居中，按实际字体的墨迹测量，尾巴不影响中心。英文不是等宽汉字格，字母数量相同也可能占不同宽度。

旧手调对白保留位置；需要重新居中时，在文字属性选择 **居中并重置对白位置**。

### 文字为什么一整行不自动折？怎么控制换行？

自动文字框默认只按你输入的显式换行分行，以便随内容缩短或增长。想按宽度换行，拖蓝色文字框手柄或设为手动框，并输入宽高。

过长内容不会偷偷缩字或丢字，会提示溢出并裁到安全区。增大气泡、缩小字号或调整手动框；恢复自动框则回到内容决定大小。

### Enter 是完成还是换行？输入法候选窗关闭是否等于退出编辑？

文字编辑中，单独 Enter 用于换行或确认组合输入；**Ctrl+Enter**完成。输入法候选窗关闭不等于 Comia 退出编辑，观察应用自己的编辑栏和输入框。

中文没有候选时先检查系统输入法模式和输入焦点。若可复现文字丢失或编辑栏异常关闭，请注明浏览器、输入法、进入编辑方式、按键与实际现象。

### 为什么连接／融合／叠加快捷键没有效果？

选中的是气泡主体还是内部文字？至少选两个同父、连续画序、可见且未锁的主体；当前每组最多 16 个。菜单会显示不可用原因。默认 `Ctrl+Alt+1/2/3`，自定义后以实际绑定为准。

### 换设备后字体变了，声效预设没有手写字体？

项目保存请求的字体名称，**不嵌入本机字体文件**。另一台电脑缺字体时会替代。默认 Noto 中文 Regular/Bold 随应用分发；声效预设保存变形和样式，不保证拥有外部商业字体。

本机字体列表由用户主动读取，权限拒绝后仍可用默认字体。完整枚举不受支持时，只显示经检测的常用列表。竖排指定标点使用打包 Noto 的字形，与正文所选字体可能不同。

<a id="shortcuts"></a>
## 快捷键

### 为什么默认快捷键在我这里不是文档里的组合？

旧自定义、主动清空的绑定会保留。打开 **文件 → 首选项… → 快捷键**查询当前命令；必要时恢复该命令默认，再确定。

改键时既要点“使用此快捷键”，也要点首选项“确定”。取消会丢弃本次草稿。冲突组合不会被无提示地覆盖。

### 按字母键没有切换工具，Delete 没有删图层？

焦点在文字／数字输入框时，按键优先编辑内容。先结束输入或点击画布；检查是否还在拖动、裁剪、手绘或输入法组合状态，以及对象是否锁定。浏览器或系统也可能拦截保留键。

不要把 `Ctrl+Y`、`Ctrl+N`、`Ctrl+O`当作本应用已有默认绑定。完整列表见[快捷键](shortcuts.md)。

## 保存、恢复与兼容

### 浏览器自动恢复是不是已经保存了文件？

不是。恢复记录保存在浏览器站点数据里，正式保存写入你选择的文件或目录。清除站点数据、换浏览器或地址可能失去恢复记录。

重要作品应保留 `.Comia.json`，并自行备份。导出 PNG/PDF 无法替代图层源文件。

### 保存后为什么仍显示未保存？

可能是下载模式尚未核对落盘，也可能在保存过程中又编辑了新内容。保存只覆盖启动保存时的快照；核对文件，再保存后续修改。

浏览器阻止下载、权限失效、磁盘或资源错误都应按提示处理，不要手动删掉未保存标记。

### 为什么“保存目录”不可用？

该功能需要浏览器原生目录接口和安全上下文。使用支持的独立桌面浏览器，或改用项目文件。自动化中内部文件系统探测通过，也不代表人工目录选择器在所有环境可用。

### 同一目录发生冲突怎么办？

检查其他标签或窗口是否保存了同一目录。保留当前作品，按提示重新打开最新目录并比较，必要时另存项目副本。复制目录时保留整个结构，不单独删内部资源或快照。

### 项目文件打不开、提示新版本或过大？

确认通过“打开项目”而非“导入素材”操作，文件完整且是 Comia 格式。当前单文件上限 **256 MiB**；原图总预算并不保证最终 JSON 一定小于此值，编码和元数据也占空间。

旧 schema 1～8可以迁移到当前 9；未知未来格式会拒绝。不要直接改 JSON 版本数字强行打开。失败时保留原文件和当前作品，按报错排查。

### 换端口后“作品没了”？

`localhost`与`127.0.0.1`、不同协议和端口都可能是不同站点。先回到原地址查恢复记录，或重新打开正式项目文件；不要立即清理浏览器数据。

## 导出与离线

### PNG 有透明底，PDF 为什么是白色？

PNG 保留透明。PDF 当前按白底整页图像输出。检查页面背景层是否透明；透明棋盘格不会导出。如果其他软件用白底查看透明 PNG，也不代表透明信息丢失。

### 为什么序号、选中框、提示面板没导出？

它们是编辑辅助。需要成品文字时自行添加文字图层；快捷键提示与节点不属于作品。

### 导出按钮不可用，或者提示像素／内存超限？

当前单边最大 8192 px、单页最多 4000 万像素，估算内存 384 MiB，PDF 累积页图像预算 256 MiB。图片解码也占预算，因此小页面配多张巨图仍可能超限。

先结束当前草稿，再核对导出倍率。明确选择较低倍率或减少页面／素材负载，应用不会自动牺牲质量。不要把尚未完成的导出当作成功文件。

### 提高导出倍率能把低清素材变高清吗？

只能增加输出像素，原图片细节仍受原图限制。PDF 物理纸张大小由页面像素与 DPI 决定，不随导出倍率变大。PDF 当前是栅格输出，不是可选中文字的矢量排版文件。

### 为什么新漫画出现紫色框线，而图层里没有这些框？

它们是漫画原稿的成品、出血、基本框和定位标记，仅辅助编辑。可在 **视图 → 显示漫画定位线** 隐藏，在页面面板的 **漫画原稿与定位线设置…** 修改；PNG/PDF不会带上它们。新项目默认8页，页数可在创建时修改。详见[原稿指南](manuscript.md)。

### 为什么默认600 DPI原稿的1×导出被禁用？

A4/600 DPI是4961×7016px，整页1×输出超过当前384 MiB估算内存预算。可自行改为0.5×输出，或创建时降低DPI；程序不会偷偷降低质量。导出仍为完整纸张，不会按成品定位框自动裁切。

### 离线打开失败或新版本没有出现？

开发服务不安装生产离线缓存。先访问完整生产构建，等待离线安装成功；相同地址才能使用其缓存。字体和静态文件缺失、配额不足、哈希不符都会导致安装失败。

清除 CacheStorage 或站点数据后需重新安装。版本切换提示出现时，先保存作品再重启；多标签可能继续使用自己的旧版本，不会自动全部刷新。请勿通过盲目清空站点数据解决版本问题而丢失恢复草稿。

<a id="reporting"></a>
## 反馈问题

准备一份最小可复现示例，并附浏览器与系统、操作顺序、实际与预期结果、错误提示、涉及的格式／尺寸／DPI／倍率。详见[开发文档的问题报告清单](development.md#reporting)。

仓库现已公开，公共 Issue 与附件可能被任何人查看。请先去除私人图片、字体文件和其他敏感内容，再提交最小示例；反馈位置的访问权限也需核对。
