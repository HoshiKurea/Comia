## 运行应用

如果应用已经打开，可直接跳到[第一张漫画](#first-comic)。以下步骤适用于本地源码运行，不需要另外启动业务后端。

1. 安装符合项目要求的 Node.js：**22.12.0 或以上**，npm **10 或以上**。
2. 获取[公开仓库](https://github.com/HoshiKurea/Comia)后，在项目目录打开 PowerShell。
3. 安装锁定的依赖并启动开发服务：

```powershell
cd E:\code\Comia
node --version
npm --version
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

4. 打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。保持服务窗口运行；在服务窗口按 `Ctrl+C` 可以停止开发服务。

项目在其他路径时，将第一行替换为你的实际目录。若 5173 正在服务已有编辑器，直接使用它；临时演示可改用另一个端口。**端口变化会改变浏览器站点存储位置**，原端口的恢复记录和首选项不会自动搬过去。

生产构建和离线使用见[开发与部署](development.md#deployment)。

## 完成第一张漫画

### 1. 新建独立项目

打开 **文件 → 新建项目…**，填写漫画名称。默认A4/600DPI、8页日式漫画，可编辑成品、出血和基本框；也可关闭漫画原稿设置，切换单位px并输入自定义画布。详见[原稿与定位线](manuscript.md)。

新项目会增加一个漫画标签，已有标签保留。**页面 → 新建漫画页**只会在当前漫画中增加页面，不会创建另一部漫画。

想复现首页展示，可使用名称“Comia · 文档演示”、关闭漫画原稿设置、自定义 **1200 × 900 px**、**300 DPI**、1页、白色页面背景。

### 2. 添加三分镜

在左侧 **组件库 → 分格版式** 中点击“上大下二”。图标名称可通过悬停查看；内容太长时点击面板标题的展开按钮。

点击后，版式直接出现在当前页中心并被选中。三个分镜是独立对象，可以分别移动、改变大小和边框。默认新建分镜的填充透明。

默认日式阅读顺序为**从右到左、从上到下**：这一版式上方为 1，下方右侧为 2，左侧为 3。序号位于分镜左上方，仅用于编辑。

### 3. 导入素材并放入分镜

1. 切换到左侧 **素材库**。
2. 点击 **＋ 文件夹**，输入“背景”，点击“确定”。
3. 选中该文件夹，点击 **＋ 导入图片**，选择你的图片；也可使用仓库内的[城市示例 SVG](../examples/city.svg)。
4. 在画布或图层面板选中分镜 1，再点素材库的 **放入选中分镜**。默认会适配分镜显示范围。
5. 对分镜 2、3 重复操作。同一原图可以生成多个独立素材实例。

也可以直接把素材卡片拖到某个分镜上，松手后自动识别并关联；按住 `Alt` 拖入可以保留自由拼贴。**直接点击素材卡片**会把素材放到页面中心，不会只是浏览缩略图。

### 4. 调整框内图片

按 `V` 回到移动工具，**按住 Alt 单击分镜内的图片**，选中素材而不是外面的分镜。

- 要改变图片位置或尺寸，在属性面板调整，或使用画布变换手柄。
- 旧版适配模式的图片可先点 **自由编辑素材**，保持当前视觉效果后转为自由变换。
- 要缩小图片实例范围，按 `C` 使用裁剪；要只隐藏部分画面，按 `Shift+C` 使用遮罩。两者分别说明于[裁剪与遮罩](user-guide.md#crop-mask)。

### 5. 添加对白

1. 切回 **组件库 → 气泡**，点击“对白气泡”。气泡直接放到页面中心。
2. 使用 `V` 将气泡移到合适位置。可在属性中输入位置、尺寸、填充色和描边。
3. **双击气泡主体**进入对白编辑，输入：

```text
Hello, Comia!
开始你的漫画。
```

4. 按 **Ctrl+Enter** 完成编辑。单独 Enter 用于换行或输入法候选确认。
5. 若需要限制一行字数，拖动蓝色对白框手柄，转为手动文字框；“恢复自动文字框”可重新让框随内容伸缩。

尾巴可从 **气泡尾** 分类添加。先选中气泡再点击尾巴组件即可关联，随后单独选中尾巴调整方向和曲线。

### 6. 保存可继续编辑的作品

打开 **文件 → 保存项目**，或按 `Ctrl+S`。在支持原生写入的浏览器中选择保存位置；其他浏览器会下载 `.Comia.json` 副本。

检查文件已保存到磁盘。PNG/PDF 是成品输出，不能替代保留图层与原素材的项目文件。浏览器自动恢复也不是正式文件备份。

### 7. 导出成品

在 **文件 → 导出倍率** 中选择倍率：

- **导出 PNG**：输出当前页；示例 1200 × 900 px 在 2× 时输出 2400 × 1800 px。
- **导出 PDF**：输出当前漫画的全部页面，顺序与页面列表一致。

分镜序号、选中边框、节点和编辑提示都不会进入成品。透明页面导出 PNG 会保留透明，PDF 则铺白底。

## 继续编辑和找回中断内容

用 **文件 → 打开项目…** 选择保存的 `.Comia.json`。不要把文件当图片拖入素材库。

若浏览器提示可恢复内容，核对作品名称与时间再恢复。恢复后仍应正式保存文件。换浏览器、换站点地址或清除站点数据后，本地恢复记录可能不可见。
