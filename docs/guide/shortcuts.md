# 快捷键与鼠标操作

[文档导航](README.md) · [使用手册](user-guide.md) · [常见问题](faq.md)

本文列出 **Windows 默认绑定**。旧项目使用者如果修改或清空过快捷键，应用会保留这些设置；菜单和“快捷键提示”面板显示的是当前实际绑定。

## 可编辑的命令快捷键

| 分类 | 操作 | 默认快捷键 |
| --- | --- | --- |
| 文件 | 保存项目 | `Ctrl+S` |
| 文件 | 另存为 | `Ctrl+Shift+S` |
| 编辑 | 撤销 | `Ctrl+Z` |
| 编辑 | 重做 | `Ctrl+Shift+Z` |
| 编辑 | 复制 | `Ctrl+C` |
| 编辑 | 粘贴 | `Ctrl+V` |
| 编辑 | 复制一份 | `Ctrl+D` |
| 编辑 | 删除选中对象 | `Delete` 或 `Backspace` |
| 图层 | 编组 | `Ctrl+G` |
| 图层 | 解组 | `Ctrl+Shift+G` |
| 图层 | 建立连接对白 | `Ctrl+Alt+1` |
| 图层 | 建立融合对白 | `Ctrl+Alt+2` |
| 图层 | 建立叠加对白 | `Ctrl+Alt+3` |
| 图层 | 关联素材到分镜 | `Ctrl+Alt+B` |
| 图层 | 解除素材分镜关联 | `Ctrl+Alt+Shift+B` |
| 工具 | 移动／点选 | `V` |
| 工具 | 矩形框选 | `M` |
| 工具 | 自由套索 | `L` |
| 工具 | 几何编辑 | `G` |
| 工具 | 分镜切割 | `K` |
| 工具 | 素材裁剪 | `C` |
| 工具 | 素材遮罩 | `Shift+C` |
| 工具 | 手绘气泡（松手自动闭合） | `B` |

其他可编辑命令默认**未绑定**，包括新建／打开项目、目录操作、关闭项目、PNG/PDF 与倍率、首选项、解散连续对白、图层排序、保存组件预设、页面操作、适应页面、主题、序号显示、尺寸吸附、面板显隐和恢复工作区。可以在首选项中自行设键，不要将 Photoshop 或其他软件的默认键直接当作 Comia 默认键。

速度线笔刷可从“组件库 → 文字与装饰”开启，目前没有独立默认字母键。

## 移动与点选工具中的手势

| 手势 | 行为 |
| --- | --- |
| 单击 | 选中当前层级可编辑的对象 |
| `Shift+单击` | 追加一个对象；对象已选中时取消它 |
| `Alt+单击` | 优先选中分镜中的图片素材 |
| `Alt+Shift+单击` | 对图片素材追加／取消选择 |
| 拖动选中对象 | 移动所选对象，多选时一起移动 |
| 方向键 | 每次微移 1 页面像素 |
| `Shift+方向键` | 每次微移 10 页面像素 |
| `Alt+拖动` | 在适用的移动／节点操作中临时关闭吸附 |
| 双击普通组 | 进入组内编辑层级 |
| 双击文字／气泡主体 | 编辑文字／主对白 |
| 按住空格再拖动 | 平移画布视图，不修改作品坐标 |
| `Shift+F10` | 对有焦点的对象或图层打开上下文菜单 |

隐藏、锁定及受祖先锁定的对象不能直接编辑。画布上的多选反馈会显示所有选中对象的框，而不是只显示图层列表高亮。

## 矩形与套索的组合键

先按 `M` 或 `L`，在画布按下鼠标开始拖动。**开始拖动时**的修饰键决定本次选区操作：

| 组合 | 选区操作 |
| --- | --- |
| 无修饰键 | 新选区，替换原选择 |
| `Shift` | 追加 |
| `Alt` | 减选 |
| `Shift+Alt` | 与原选择取交集 |
| `Esc` | 取消正在绘制的选区，保留此前选择 |
| `V` | 返回移动／点选工具 |

菜单下固定工具选项栏还可以设置“相交／完整包含”和选择范围。这里选中的是**整个组件或素材对象**，不是图片中的像素。

同一个 `Alt` 在不同工具中含义不同：`V` 下优先拾取图片，`M/L` 开始拖动时减选，节点拖动时临时自由移动。

## 单个节点的快速编辑

| 手势 | 行为 |
| --- | --- |
| 选中分镜后，`Ctrl+拖动实际顶点` | 直接调整一个顶点，无需先切工具 |
| `G` | 进入几何工具，显示可编辑节点 |
| `Ctrl+方向键` | 微调当前活动节点，每次 1 页面像素 |
| `Ctrl+Shift+方向键` | 微调当前节点，每次 10 页面像素 |
| `Alt+←` / `Alt+→` | 切换活动节点 |
| 节点拖动中按住 `Alt` | 临时解除横纵和相邻节点磁性对齐 |
| `Esc` | 取消当前节点编辑预览 |

直接编辑必须命中实际顶点；点击边中点或外部空白不会被视为单节点编辑。节点默认优先沿页面横轴、纵轴移动，并辅助对齐相邻节点；明显偏离后会脱离吸附。旋转对象的坐标轴仍以页面横纵方向为依据。它提供磁性约束，不通过降低帧率制造卡顿。

## 文字与确认操作

| 按键 | 行为 |
| --- | --- |
| `Enter`（文字编辑中） | 换行；输入法候选仍在组合时用于输入法确认 |
| `Ctrl+Enter`（文字编辑中） | 完成文字编辑 |
| `Esc` | 取消当前编辑或草稿；具体对象由当前编辑状态决定 |
| `Enter`（裁剪等支持确认的会话中，输入框外） | 应用当前有效草稿 |

在输入框内，字母、删除键和复制粘贴优先用于输入内容，不应删除画布对象。系统输入法、浏览器插件或操作系统保留快捷键可能先拦截组合键。

## 修改快捷键

1. 打开 **文件 → 首选项… → 快捷键**。
2. 搜索命令名，或滚动到对应类别。
3. 点击某个命令的修改按钮，按下新的组合键，再点 **使用此快捷键**。
4. 每个命令最多有两个组合，可添加备用绑定，也可移除已有绑定。
5. 处理冲突提示。应用不会把同一组合无提示地分配给多个冲突命令，也不会覆盖旧自定义。
6. 点击首选项的 **确定**，整体保存；**取消**丢弃本次首选项草稿。

可以恢复单个命令、本类或全部默认。全部恢复会同时重置其他首选项，请核对后再确定。`Esc`、空格平移、方向微移和上下文节点手势目前为固定基础交互，不属于可改键命令。

首选项保存在当前浏览器站点，供所有漫画共用；不会写进 `.Comia.json`。同一作品换浏览器后，快捷键可能不同。

## 查看当前对象可用的操作

打开 **窗口 → 快捷键提示**。悬停组件、素材或选中画布对象时，活动面板展示适用操作及实际按键；未设置的命令会显示“未设置”。它可以停靠左侧、右侧、组合或浮动，不覆盖在画布对象旁边。

气泡快捷键需选中有效的气泡主体；选择内部文字不能替代选择气泡。连接、融合、叠加的对象条件见[连续对白](user-guide.md#bubbles)。

按键没有效果时，先检查焦点、当前草稿是否结束、对象锁定和首选项实际绑定，再看[快捷键排查](faq.md#shortcuts)。
