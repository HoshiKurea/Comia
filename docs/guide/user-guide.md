## 项目、页面与背景

### 新建另一部漫画

**文件 → 新建项目…**：输入名称，选择纸张、方向、DPI 和背景后创建。新项目在独立标签中打开，不把现有漫画的页面合并进来。

项目标签之间可切换；每个项目分别维护内容、撤销历史和保存目标。关闭标签时，未保存内容需要按提示处理。标签保留是当前应用会话的行为，不代表刷新后所有标签及历史自动重建。

### 管理当前漫画的页面

- **页面 → 新建漫画页**：在当前漫画增加页面。
- **页面 → 重命名当前页… / 删除当前页…**：操作当前页，最后一页不能删除。
- 在 **页面面板**点击缩略图切页；拖动页面条目改变顺序，插入标记提示目标位置。
- 页面排序会改变整部 PDF 的输出顺序，不会重新编号已有分镜。
- 缩略图显示失败时，点击对应的重试按钮。重试只刷新预览，不修改作品。

### 纸张与尺寸

**页面 → 页面设置…**可修改纸张和 DPI。内置 A4 为 **210 × 297 mm**，B4 为 **ISO B4：250 × 353 mm**；需要 JIS B4 时请自行设置尺寸，不要把两种 B4 混同。

自定义宽高使用页面像素，当前范围为每边 **16～16384 px**，DPI 为 **72～600**。毫米与像素换算：

```text
像素 = round(毫米 ÷ 25.4 × DPI)
毫米 = 像素 ÷ DPI × 25.4
```

改变页面尺寸不会自动缩放图层。原内容保持自己的位置与大小，超出新页面的部分会在导出时裁掉；应用前先检查预览。

在页面面板中可设置漫画阅读方向。默认右到左、上到下；这一方向用于新建批量分镜和切割结果的排序，不会随移动而改写已有创建编号。

### 独立编辑最底层页面背景

在图层面板选中 **页面背景**，调整背景样式。支持纯白、透明、暖色纸、单边框、双边框和水印纸。

可按模板编辑颜色与透明度、框线与内边距，以及水印文字、角度、字号和间距；完成后提交，取消则丢弃草稿。背景是铺满整页的专用底层，不等同于可任意缩放的普通图片。

删除页面背景后，页面尺寸仍存在，底部变为透明。工作区的棋盘格仅用于显示透明度。**透明 PNG 保留透明；PDF 页面为白底**。分镜自身若填了不透明颜色，仍可能挡住下方内容。

## 工作区、面板与顶部菜单

### 界面区域

| 区域 | 用途 |
| --- | --- |
| 顶部菜单 | 文件、编辑、图层、页面、视图、窗口 |
| 菜单下工具选项栏 | 始终占据固定高度，切换工具时显示对应选项，复杂参数从“更多”展开 |
| 项目标签 | 切换独立漫画项目 |
| 画布旁工具栏 | 移动、框选、套索、分镜切割、素材裁剪、素材遮罩、气泡笔刷 |
| 左侧默认面板组 | 组件库、素材库、页面 |
| 右侧默认面板组 | 快捷键提示、属性、图层与历史记录 |
| 画布 | 编辑当前页，显示选择框、节点和分镜序号等辅助信息 |

### 移动、浮动和组合面板

共有七种面板：组件库、素材库、页面、属性、图层、历史记录、快捷键提示。

1. 拖动面板组标题处的移动手柄，移动整组。
2. 拖动单个标签，将该面板从组合中分离。
3. 拖到左右停靠区或其他面板组的提示区域，按预览进行停靠、叠放或标签组合。
4. 在空白区域松手形成浮动窗；浮动窗可移动、调整尺寸。
5. 面板标题的菜单提供布局操作，适合不方便拖动时使用。

关闭面板只隐藏它，不会删除内容。通过 **窗口**菜单重新显示。布局混乱时用 **窗口 → 恢复默认工作区**。

侧边栏使用固定高度，没有整栏滚动条。内容超出时，可以在面板内部滚轮滚动；滚动条隐藏不代表没有更多内容。点击标题的 **展开**按钮，在大窗中编辑；收回后返回原面板，保留该操作的草稿。

### 查看快捷键提示

悬停组件或素材，或选中画布对象时，“快捷键提示”面板显示适用操作。悬停不会改变画布选择。面板中的按键随首选项更新；没有默认键的操作会显示未设置。

## 选择、变换与图层

### 单选与多选

按 `V` 使用移动／点选工具：单击选择；`Shift+单击`追加或取消对象；多选后拖动会一起移动，画布会显示每个选中对象的边框。

分镜外框与内部图片重叠时，使用 **Alt+单击**优先选择图片；**Alt+Shift+单击**对图片进行多选。也可以展开图层树选择图片子层。

### 矩形框选与套索

- `M`：从起点拖到终点形成矩形选区。
- `L`：拖动绘制自由套索，松手后按圈出的区域选择。
- 顶部选项可设置新选区、追加、减选、交集，以及“相交／完整包含”和选择范围。
- 开始拖动时 `Shift` 追加，`Alt` 减选，`Shift+Alt` 取交集。
- 默认在当前编辑层级选择，普通组作为整体；选择范围可切为素材。

这两种工具选中的是完整对象。默认相交判断依据对象显示外接范围，不是逐像素颜色或透明度判断；可见但被其他对象挡住的对象也可能被框选。隐藏、锁定和页面背景不参加普通区域选择。

`Esc` 取消未完成选区；取消不会写撤销历史。按 `V` 再移动所选对象。双击普通组可以进入组内层级，返回上层后再选其他同级对象。

### 变换与精确输入

使用画布手柄缩放、旋转；属性面板可直接输入 X、Y、宽、高和角度。**位置是相对父容器的坐标，尺寸是局部尺寸**；在旋转或嵌套组内编辑时，不要把它当作页面绝对坐标。

画布滚轮用于平移，`Ctrl+滚轮`围绕鼠标位置缩放视图；**视图 → 适应页面**重新居中查看整页。视图变化不修改素材尺寸，也不进入内容历史。

方向键每次移动 1 页面像素，`Shift+方向键`每次 10 像素。属性中的滑块旁提供可编辑数值；透明度以百分比显示，颜色还可以使用带 Alpha 的 RGBA 值。

输入越界、空值或无效数值时，应用会提示或恢复有效值，不应产生 NaN 对象。被锁定的对象及锁定祖先中的对象不能编辑。

### 图层与历史

图层面板显示真实父子结构，支持名称、颜色标签、搜索、隐藏和锁定。普通组可以容纳组件；分镜的图片子层用于关联素材，独立分镜之间不会成为彼此的子层。

**图层**菜单提供编组、解组及置顶／上移／下移／置底。批量排序需要兼容的同父层级；跨父层级或锁定对象会被拒绝，而不是只移动部分选区。

内容编辑通过统一事务进入历史。拖动预览不会逐帧生成记录，确认后一笔对应一次可撤销操作。**历史记录**面板可以跳到已有状态；撤销后进行新编辑会丢弃原来的重做分支。历史最多保留 200 次事务，不能当作永久文件版本库。选择、画布视图、面板布局和首选项不属于内容撤销。

## 分镜、分格与切割

### 添加单个框或版式

组件库以图标按类别排列。点击组件即放在页面中心并选中；拖动组件时，半透明预览跟随鼠标，即使经过画布外也可见。按 `Esc` 取消拖放。

分镜形状包含矩形、圆角、椭圆、三角、菱形、梯形、平行四边形和五／六／八边形。分格版式包含上下二格、左右二格、三横条、三竖条、四横条、四格、六格及大小格组合。

新分镜默认透明填充，仍有可编辑边框。通过版式、等分、随机或切割生成的每块分镜都是**同级独立对象**；要整体移动，可显式选中它们再编组。

### 行列等分与随机分格

打开 **组件库 → 分格工具**：

- **行列等分**：设置行数、列数、留白和间距，预览后应用。行列范围为 1～8。
- **随机分格**：选择当前页新增布局，或对有效选中分镜进行切分；设置数量、边距、横纵间距、角度、布局风格和随机种子，预览后应用。

随机数量为 2～24。相同种子与参数用于复现同一布局；“换一组”改变种子。默认日式阅读顺序从右到左、从上到下生成这一批序号，结果仍可逐框修改。随机生成不调用 AI 服务。

### 手绘与多边形分格

选择对应分格工具，在画布绘制轮廓或逐点建立多边形；完成绘制后进入节点修正，再完成或取消。

自交、过小或退化轮廓会提示错误，保留修正机会，不提交无法使用的分镜。修正时应保持轮廓简单、面积有效；过度复杂的细碎轮廓更适合图片或气泡，而不是分镜。

### 节点与单边调整

选中分镜按 `G`，或直接 `Ctrl+拖动实际顶点`。节点默认磁性辅助横向、纵向与相邻节点对齐；明显偏离可脱离，`Alt` 临时关闭吸附。

活动节点还可用 `Ctrl+方向键`微调，`Ctrl+Shift+方向键`加速，`Alt+←/→`切换节点。移动一个节点可以改变单条边的长度或倾斜；若要平移整条边，请分别调整两端节点并利用对齐辅助。

无效变形不会替换正式轮廓，取消恢复进入编辑前的形状。屏幕吸附与页面坐标变换由编辑器处理，缩放画布不应改变页面几何精度。

### 分镜切割

按 **K**，选择目标分镜或在画布拾取目标，拖动直线穿过轮廓。顶部选项提供切缝等参数，预览合法后应用；需要多块时继续切割目标块。切缝可设为 0，当前默认 16 页面像素。

切割结果独立同级。目标绑定的普通图片会在各新框中形成独立实例，保持原画面映射，再按新框分别裁切；原图资源共享，实例参数可单独编辑。存在破格素材时，需要先解除关联或改为普通模式，再切割。锁定、退化或无法产生有效块的切割会拒绝，不产生空层。

### 编号规则

序号在**整个漫画项目**内唯一，位于分镜左上方；不参与 PNG/PDF 输出，也不是图层中的文字对象。

**普通新建**使用当前实际存在的最大序号加一；没有分镜时从 1 开始：

| 当前现存编号 | 新建编号 |
| --- | --- |
| 1、2、3 | 4 |
| 删除末尾后只剩 1 | 2 |
| 1、3、4，删除的是中间 2 | 5 |

**切割或替换分格**从目标号连续插号：分镜 k 变为 N 块，新块为 k～k+N−1；后续现存编号增加 N−1。例如已有 1、2、3，切割 1 为三块后得到新 1、2、3，原 2→4、原 3→5。

自动图层名跟随编号，自定义图层名保留。移动、页面排序不会重排创建编号。可以用 **视图 → 显示分镜序号**控制编辑标识。

## 素材库、文件夹与关联

### 导入和复用

**素材库 → ＋ 导入图片**导入已有图片；也可以拖放文件到素材库，或在画布获得焦点时粘贴图片。

支持 PNG、JPEG、WebP、GIF、AVIF 和受限制的 SVG，具体解码取决于浏览器。动画只作为静态素材使用，取可确定的完整首帧。SVG 的脚本、外部资源等不接受；需要完整复杂 SVG 时，先在原工具转为 PNG。

素材原图保存在漫画项目中。点击卡片生成页面中心的独立图片实例；多次放置不会把所有实例的参数绑在一起。相同内容会去重，不会为了重复放置再保存一份相同原图。

### 文件夹分类

1. 点击 **＋ 文件夹**，命名并确定。
2. 选择文件夹后导入，新素材归入该文件夹。
3. 拖素材到文件夹，或使用素材条目的分类操作，调整归类。
4. 使用面包屑返回上级，切换网格／列表，输入名称搜索当前范围。

“全部素材”显示库中素材，“未分类”显示没有文件夹的素材；普通文件夹主要显示其直接内容，不自动平铺所有子目录。已去重的原素材继续保留原分类。

删除文件夹将内容与子文件夹移到上级，不删除原图或画布实例；分类编辑可撤销。**移出素材库**也不删除已放到画布中的实例；从画布删除实例不会自动清空库原图。

### 关联与解除关联

- 从素材库拖到分镜显示区域，松手自动识别并关联；按 `Alt` 拖入可保留自由素材。
- 选中一个分镜与需要关联的素材，按 **Ctrl+Alt+B**，或用图层菜单／右键操作。
- 选中已关联的图片，按 **Ctrl+Alt+Shift+B**解除，或使用图片属性中的解除入口。
- 根据位置重叠显示的关联建议用于减少操作；普通移动不会逐帧强制改变父层级。

关联后仍可以单独选中和编辑素材。使用 `Alt+单击`进入图片选择，调整位置、旋转、尺寸或裁剪。普通模式下超出分镜边界的内容会被分镜遮住。

整体或局部破格后，在分镜框内的重合区域普通单击仍默认选择分镜，拖动会带着关联素材一起移动。点击框外可见的破格部分可直接选择素材；用 `Alt+单击`或图层面板明确选中素材后，可以在框内继续单独拖动它。

## 裁剪、遮罩与破格

| 功能 | 可见内容 | 实例选择框 | 素材库原图 |
| --- | --- | --- | --- |
| 裁剪 `C` | 限定图片实例的源范围 | 随裁剪改变 | 保留 |
| 遮罩 `Shift+C` | 在现有实例上隐藏部分区域 | 保持现有范围 | 保留 |
| 分镜关联 | 默认限制在所属分镜内 | 不替代实例裁剪 | 保留 |
| 破格 | 允许越过所属分镜的裁剪边界 | 仍由实例与裁剪决定 | 保留 |

### 真正裁剪实例范围

1. 选中图片，按 `C`；也可以从工具直接点击图片作为目标。
2. 拖出裁剪框，或用八个手柄和范围数值调整。
3. 点击 **应用裁剪**，或在输入框外按 Enter。
4. 实例宽高、画布选择框、命中范围与输出同步使用新裁剪范围。

**恢复裁剪**重新使用完整资源。此操作不是永久删除素材文件中的像素，也不会影响另一个使用相同原图的实例。旋转、缩放和绑定关系保留对应映射。

### 独立遮罩

按 `Shift+C`，选择矩形、椭圆或多边形遮罩，在画布调整。遮罩控制哪些区域可见，实例选择范围不因此收缩。

图片属性可启用／停用／移除遮罩，并控制 **链接图片与遮罩**：链接时共同移动，取消链接后可以分别调整。切换图片与遮罩编辑目标，避免把“移动图片”误当成“移动窗口”。

裁剪与遮罩可以叠用。移除遮罩只显示**当前裁剪范围**；若还要恢复原图全范围，另行恢复裁剪。旧适配分镜的“调整框内图片”用于改变取景，不等于 `C` 的实例裁剪。

### 整体和局部破格

在图片属性的 **素材破格模式**中选择：

- **普通**：受所属分镜边界遮罩。
- **整体破格**：整张实例允许越过所属分镜边界。
- **局部破格**：通过矩形、椭圆或多边形区域指定可越界部分，可继续修正或移除。

破格只解除对应的所属分镜裁剪，不移除图片自身遮罩，也不让内容突破最终页面范围或无视其他祖先约束。人物头部、武器等可先用素材自身遮罩分离，再通过局部破格显示。

破格不会自动把图片放到所有相邻分镜之上。前后遮挡遵循实际图层顺序；需要改变叙事遮挡时，调整所属分支的层级，而不是期望“破格”取代排序。

<a id="bubbles"></a>
## 气泡、尾巴与连续对白

### 组件气泡与样式

气泡分类包含对白、方框、圆形、云朵、尖刺、柔和手绘、粗糙速写、不规则多边形和波浪紧张轮廓。

点击添加后，可以编辑轮廓、尺寸、填充、原中心边框、内描边和外描边。内外描边分别有开关、宽度与 RGBA 颜色；透明度允许半透明效果。当前描边宽度范围为 0～256 页面像素。

边缘抖动、种子和笔压参数用于形成可控手绘感。参数变化从基础节点派生，不逐次破坏原节点；关闭抖动可以回到基础轮廓。**重新生成轮廓**会替换作者节点，应与单纯改变抖动区分。

### 手绘气泡笔刷

1. 按 `B` 或点击工具栏的气泡笔刷。
2. 在顶部选择干净线条、柔和手绘或粗糙速写；“更多”调整平滑、精度、闭合距离、抖动、笔压和描边。
3. 在页面内按住鼠标绘制闭合轮廓，松手进入修正状态。
4. 拖动节点修正；开放轮廓可把终点移近起点，或重新绘制。
5. 点击 **完成手绘气泡**提交；取消不会留下空图层。

当前默认闭合距离为 12 屏幕像素，一笔最多 4096 个采样点，拟合结果为 8～32 个可编辑节点。自交、退化、过度复杂或无法满足精度的轮廓会给出错误，不静默降低输出质量。

这是一种可编辑的矢量气泡笔刷，不是任意像素绘画笔刷。即使在分镜范围内绘制，气泡仍作为自由组件归属到合适的普通组／页面，不成为仅容纳图片的分镜子层。

### 独立尾巴

先选中气泡，再从“气泡尾”点击短直、细线、弯曲长、多泡内心、锯齿喊叫或平头低语尾。关联尾随气泡移动，也可以在图层中单独选中，调整 360°方向、连接点和直线／折线／样条路径。

按住 `Alt` 的自由放置用于不自动关联的尾巴。每个气泡最多绑定四条尾；实心尾支持对应轮廓的内外描边，细线尾使用中心线样式。

### 连续对白

用 `Shift+单击`选中至少两个**气泡主体**，再使用：

| 模式 | 操作 | 结果 |
| --- | --- | --- |
| 连接 | `Ctrl+Alt+1` | 多个主体保留，以连接路径串起来 |
| 融合 | `Ctrl+Alt+2` | 以联合轮廓形成连续气泡，交叠内部不留下硬接缝 |
| 叠加 | `Ctrl+Alt+3` | 保留重叠关系，按属性调整叠加效果与透明度 |

菜单入口是 **图层 → 建立连接／融合／叠加对白**。需要同父容器、连续画序、可见且未锁定的气泡，当前一组为 2～16 个。选择内部文字、跨父容器或混入不兼容对象时，命令会提示条件不满足。

融合的描边沿最终联合外轮廓绘制，内外色带不分别穿过成员接缝。使用 **解散连续对白**返回独立成员；修改与解散都可通过事务撤销。

<a id="text"></a>
## 对白、独立文字与声效字

### 编辑对白

双击气泡主体创建或进入主对白，输入中文或英文。单独 Enter 换行／确认输入法候选，**Ctrl+Enter**完成，**Esc**取消本次编辑。

文字使用实际字体测量。字体、字号、行距、字距和方向可在属性面板调整；需要本机字体时点击读取入口，由浏览器按能力和权限提供。

### 自动框与手动换行框

**自动文字框**默认随内容收缩或扩张，只按显式换行分行。等宽中文四字缩为三字时，文字框跟随缩短；英文使用字体实际字宽，不能按字母个数硬算等宽格。整个文字墨迹在气泡主体安全区横纵居中，尾巴不参与计算中心。

**手动文字框**用于限制行宽：拖蓝色框的八个手柄，或点击属性中的手动框入口并输入宽高。英文尽量按单词换行，过长单词可进一步按字符拆行；字号与气泡尺寸不因此被拉伸。`Shift`拖柄保持比例。

手动框尺寸不会因气泡缩放而自动重算成另一个行宽。点击 **恢复自动文字框**重新按内容伸缩；**居中并重置对白位置**可统一旧手调位置。旧作品中人为调整过的文字位置默认保留，不无条件改居中。

空串保留一行编辑空间，不插入占位文字。内容超出安全区时保留完整文本并提示溢出，显示和输出按安全区裁切；应用不会偷偷删除文字或缩小字号。请缩小字号、增大气泡或调整换行。

### 独立文字与声效字

组件库 **文字与装饰**提供普通文字、音效字及重击、裂响、静默、弧形呼喊等模板。它们可放在任意位置，不必放进气泡。

通过属性调整描边、倾斜、变形和文字效果。所谓声效模板主要是对象与效果参数，不意味着附带任意商业手写字体；字体来自打包 Noto 或当前设备可用字体。

复制或移出主对白为独立文字，会保持当前文字视觉位置与换行。复制整个气泡则保留对白的自动／手动模式。

竖排支持基础排布及指定标点替代，但不等于完整日文禁则、纵中横或复杂 RTL 文字排版系统。跨设备字体差异见[常见问题](faq.md#fonts)。

<a id="speed-lines"></a>
## 速度线与集中线

在 **组件库 → 文字与装饰 → 速度线笔刷**开启，按住拖动，松手形成一笔。拖动起终点决定线条方向；笔刷设置可调整范围、密度、线宽、不规整度和颜色。

生成的每条速度线保持**笔直**，间距、长度与粗细可以不规整。它不是把手的抖动直接变成弯曲线条；一次笔刷结果可以继续调整并保存参数预设。

“集中线”是另一种可放置的装饰组件，适用于向中心汇聚的表现。不要把它与速度线刷痕或 AI 生成功能混同。

<a id="presets"></a>
## 自定义组件和笔刷预设

### 保存现有组件或组合

1. 在画布创作或修改分镜、气泡、尾巴、文字、声效字或速度线。
2. 选中要保存的组件，必要时多选组合。
3. 点击属性中的 **保存为组件预设…**，或组件库的 **保存选区为预设…**。
4. 核对保存内容，命名并确定。预设出现在“自定义组件”分类。

导入图片不属于组件预设范围，继续由素材库管理；混合选区中被排除的图片会在保存说明中提示，避免误以为原图一起保存了。

再次点击或拖放预设会生成独立副本，分配新对象 ID；分镜获得新的合法编号。编辑副本不会追溯修改原实例或其他副本。可通过预设条目操作重命名、删除或用当前选区更新。

### 固定图案与笔刷参数

| 保存方式 | 再次使用 |
| --- | --- |
| 固定组件图案 | 放置保存的轮廓、文字、尾巴与样式副本 |
| 气泡笔刷参数 | 启用保存的笔触设置，接着手绘新的轮廓 |
| 速度线笔刷参数 | 用保存的刷痕设置绘制新的一笔 |

预设存放在**当前漫画项目**中，随项目文件保存；不是所有漫画共享的全局笔刷目录。

<a id="preferences"></a>
## 首选项

打开 **文件 → 首选项…**：

| 类别 | 设置 |
| --- | --- |
| 常规 | 跟随系统、浅色、深色主题 |
| 编辑辅助 | 分镜序号显示、16 倍数尺寸吸附 |
| 导出 | 默认导出倍率 |
| 快捷键 | 命令搜索、改键、备用组合、冲突提示、恢复默认 |

16 倍数尺寸吸附用于尺寸调整，不等于把所有对象位置自动锁到 16 像素网格。节点磁性横纵辅助是独立的上下文行为。

点击 **确定**提交整份首选项草稿，取消放弃。设置保存在当前浏览器站点并供所有漫画使用，不写进漫画内容、不进入内容撤销。多窗口并发修改发生冲突时，请按提示重新加载设置再编辑。

活跃的拖动、草稿、文字组合输入或文件操作可能暂时限制首选项入口；先完成或取消当前动作。完整改键步骤见[快捷键文档](shortcuts.md)。

<a id="storage"></a>
## 保存、恢复与兼容

### 项目文件

**文件 → 保存项目** / `Ctrl+S`保存当前漫画的页面、图层、素材、文件夹和组件预设。**另存为…** / `Ctrl+Shift+S`选择另一个目标或下载副本。

项目文件通常为 **`.Comia.json`**，包含可编辑数据和图片资源。通过 **文件 → 打开项目…**读取，而不是作为图片导入。面板布局、全局首选项、画布选择和完整撤销历史不是可携带的项目文件内容。

支持 File System Access 的安全上下文浏览器可以写入所选文件；其他浏览器使用下载回退。下载发起不证明文件落盘；应用会区分未核对的下载和实际写入完成，请检查文件。

保存使用当时的作品快照。保存期间继续编辑产生的新状态可能仍显示未保存；这表示新改动没有包含在刚才的文件中，应再次保存，不是要求清除脏标记。

### 项目目录

在浏览器支持目录选择时，可用 **保存到项目目录…**和**打开项目目录…**。目录保存按快照与资源管理，不是让素材无限引用电脑上的原路径。

迁移目录时保留整个目录结构，不只复制某个 JSON 或单独删内部资源。遇到其他标签修改同一目录的冲突，按提示重新打开并核对，再保存；不要强行覆盖不明更新。浏览器不支持目录接口时，使用项目文件。

### 浏览器本地恢复

自动恢复记录保存在浏览器 IndexedDB，按应用提示选择恢复版本。它不能代替手动保存，不自动把“未保存”改为“已保存”。

换浏览器、换协议／主机／端口或清除站点数据会影响恢复记录可见性。正式 `.Comia.json` 文件和完整项目目录是迁移设备与备份的主要方式。

### 格式版本

当前内部作品数据为 schema 9，可迁移读取旧 schema 1～8；保存后使用当前格式。比当前应用更新、无法识别的格式会拒绝打开并保留现有作品。不要假定旧版 Comia 可以反向读取新保存的文件。

复杂的新能力仍沿用已授权暂定方案：矢量气泡笔刷、保留原图的实例裁剪、全项目切割顺延、旧手调文字位置保留等。对应产品决策的未确认状态保留在[架构与暂定决策](../architecture.md#provisional)中，本手册描述当前实际行为。

<a id="export"></a>
## PNG 与 PDF 导出

### 输出内容

- **文件 → 导出 PNG**：当前页，保留页面背景与素材的实际透明度。
- **文件 → 导出 PDF**：当前漫画的所有页面，按页面列表顺序，每页铺白底。
- 分镜序号、选中框、节点、拖动预览、快捷键提示和透明棋盘格不进入输出。
- 导出等待图片与字体准备，使用开始时的作品快照。取消不会生成一份有效的半成品文件。

PDF 使用整页栅格图像封装，并非可编辑矢量 PDF；文字不可在阅读器中作为文本选择。可编辑源请保留项目文件。

### 倍率、像素与纸张

倍率可选 **0.25×、0.5×、1×、2×、4×**。

```text
输出像素宽 = round(页面像素宽 × 倍率)
输出像素高 = round(页面像素高 × 倍率)
PDF 物理宽毫米 = 页面像素宽 ÷ DPI × 25.4
PDF 物理高毫米 = 页面像素高 ÷ DPI × 25.4
```

提高倍率增加图像像素，不改变 PDF 的物理纸张尺寸。对原图低分辨率素材放大导出，也不会凭空补出原图细节。

### 大图与资源限制

当前输出预检上限包括：单边 **8192 px**、单页 **4000 万像素**、估算内存 **384 MiB**，以及 PDF 累积页图像预算 **256 MiB**。估算还考虑当前解码素材，不仅是画布宽高。

页面允许的尺寸范围大于一次导出的画布预算，所以合法大页面也可能无法按 1× 或 4× 导出。超限时应用提示具体问题，不暗中降低倍率；可明确选择更低倍率，或减小页面／资源负载后重试。

字体替代、输出失败或资源未准备好的信息应先处理。常见处理步骤见[导出问题](faq.md#export)；实际性能证据与测试范围见[核验说明](development.md#verification)。
